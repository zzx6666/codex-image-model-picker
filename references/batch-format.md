# 批量任务 JSONL 格式

每行写入一个 JSON 对象。每个任务必须有 `prompt`，并可以覆盖生图或输出设置。

```jsonl
{"prompt":"白色背景上的蓝色陶瓷杯","name":"蓝色陶瓷杯"}
{"prompt":"晴空中的红色纸风筝","name":"红风筝与晴空","model":"gpt-image-2.5-sunburst","size":"1536x1024","quality":"low","n":2}
```

支持的字段是 `prompt`、`name`、`size`、`quality`、`n`、`out` 和 `model`。相对路径以 `--out-dir` 为基准解析。空行会忽略。

默认把图片直接保存到当前工作目录。每个任务应填写按画面重点概括的 `name`，并省略 `out`；程序会按 JSONL 任务顺序自动生成 `1. 名称.png`、`2. 名称.png` 等编号。已有的最大编号会自动跳过。`n` 大于 1 时，每个变体也占用一个连续编号。只有用户明确要求自定义路径时才填写 `out`。

任务会在首次请求前完成参数和输出路径校验，未知字段或非法值不会产生部分计费。`--fail-fast` 会停止启动后续任务，并在 JSON 汇总中分别报告 `succeeded`、`failed` 和 `skipped`。任一任务失败时命令以非零状态退出。
